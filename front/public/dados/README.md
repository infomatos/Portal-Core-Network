# Base de demandas

Coloque a planilha de demandas neste diretorio com o nome:

```txt
demandas.xlsx
```

O assistente le a primeira aba do arquivo e reconhece colunas com nomes como:

```txt
id, codigo, numero, demanda, chamado
titulo, descricao, assunto, nome
status, situacao, estado
responsavel, owner, focal, analista
prioridade, criticidade, severidade
data_abertura, abertura, criado_em, data de abertura
prazo, data_prazo, vencimento, deadline
ultima_atualizacao, atualizacao, modificado_em, ultima atualizacao
area, equipe, gerencia, squad
```
